## About Me

I work where data, software, and manufacturing quality meet. At BMW Group, I wrote SQL and built dashboards in Oracle APEX, analyzed KPI data for managers, and validated vehicle software on current and upcoming series models. I'm now focusing on data analytics and currently studying in the UT Austin McCombs Data Analytics Essentials program.

## Run It Locally

1. Clone the repo: git clone https://github.com/pkali076/PortfolioKalinowski.git
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**, or just open `index.html` in a browser.
